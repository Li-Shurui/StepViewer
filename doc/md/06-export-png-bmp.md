# 导出 PNG/BMP

把当前显示的图像一键保存为 PNG 或 BMP 文件，用于报告、对比和归档。

## 用户界面

- 工具栏 **Export...** 按钮，快捷键 `Ctrl+E`；
- 仅在成功加载图像后可用；
- 弹出保存对话框，过滤器为 `PNG 图像 (*.png)` / `BMP 图像 (*.bmp)`；
  文件名不带扩展名时按所选过滤器自动补全。

## 导出内容

导出的是**当前屏幕上看到的内容**：

- 合成视图 → 转换后的 RGB 图像；
- 平面视图 → 该平面的灰度图（原始分辨率）；
- 多帧文件 → 当前帧。

建议文件名自动带上上下文：`<原名>[_frameN][_u].png`，例如
`capture_frame3_u.png`（第 3 帧的 U 平面）。

## 实现要点

- `YuvViewer::exportImage()` 直接使用缓存的 `m_image`
  （`QImage::save()` 按扩展名推断格式），不重新读取或转换原始数据；
- 导出失败通过 `reportError()` 显示在图像区和状态栏，
  成功则在状态栏给出目标路径；
- 导出动作与缩放动作一样在 `clear()` / `enableZoomActions()` 中
  随图像有无自动启用/禁用。

## 备注

- BMP 不支持 alpha 通道，RGBA 源导出 BMP 时 alpha 会被丢弃；
- 高 bit 深度格式（P010 等）当前导出的是转换后的 8 位图像。
